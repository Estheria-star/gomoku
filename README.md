# 五子棋 · 学习反制版

🎮 **在线游玩 → https://wuziqi.startian.top/**

> 单文件五子棋（约 16.8 MB）：内嵌 [Rapfi](https://github.com/dhbloo/rapfi) 引擎（WASM）+ 自研「学习反制」系统 + DeepSeek「灵拙」陪伴层 + 联机大厅与房间对战

## 玩法

- 直接打开上方链接；或下载 `index.html` 后双击本地玩
- **难度**：简单 / 中等 / 困难（Rapfi 经典引擎）/ **灵拙**（mix9 神经网络）/ 快速开始（本机 AI）
- **灵拙思考强度**：极速 / 标准 / 更强 / 极限（逐档增加搜索预算）
- 可自选先后手；支持悔棋、新游戏、保存思考日志、清除 AI 记忆
- 可选接入自己的 DeepSeek API Key：灵拙会观战 / 陪你说话（Key 仅存在于本机浏览器，直连官方接口，不经第三方）

## 联机对战（2026-10 新增）

- **联机大厅**：点侧栏「🌐 联机大厅」，实时看到所有在线房间（房间号 / 人数 / 对局中）；一键创建房间或输入房间码加入
- **房间对战**：双方落子实时同步；支持**申请悔棋**（对方同意制）、**再来一局**（换边再战）、**认输**、**房间聊天**
- **昵称**：给自己起个名字，大厅、座位、聊天全程显示；改名字对方实时可见
- **先后手**：默认每局随机分配，房主也可选择「随机 / 自己先手 / 对方先手」
- **零后端**：基于公共 MQTT 服务（多节点并行连接，跨网络可达），无需注册、无需服务器
- **抗抖动**：每条消息携带完整棋谱 + 心跳对账，掉线重连 / 丢包后自动恢复同步

## 「学习反制」是什么

AI 会针对**你**学习：败因形状（8 向对称匹配、时效衰减）、开局习惯与应手战绩、位置热度、打法画像（激进 / 稳健）；不同难度的记忆分桶隔离、互不污染；灵拙档另有独立的自对弈训练棋谱。

## 技术说明

- **网页版为「拆分版」**：`index.html` 首屏很小（约 176KB），Rapfi 引擎资源放在 `assets/` 按需异步加载（浏览器会缓存）
- 单文件版（约 16.8MB 全内嵌、双击即玩）是项目源件；网页版由 `build_web.py` 从源件自动生成
- 因此：**首次打开几秒出棋盘**；切到「困难 / 灵拙」首次使用时会先下载一次引擎资源（日志区有下载进度）
- 引擎解码与搜索都在 Web Worker 中进行（不阻塞界面）；Worker 不可用时自动回退主线程
- 落子由本机 AI / Rapfi 引擎决定，DeepSeek 仅负责语言输出
- 联机走 MQTT over WebSocket（公共 broker，多节点并行 + 消息去重）；对局状态由完整棋谱同步，天然幂等、可自愈
- 不同网址（本地 / Pages / 局域网）下的存档互相独立（浏览器 localStorage 隔离）
